# AulaContigo 🎓

**Aprende, pregunta y sigue avanzando.**

Plataforma educativa inteligente para estudiantes, profesores y orientadores.

## Base inicial
- Frontend responsive con HTML, CSS y JavaScript modular.
- Horario vertical por día, clase y hora.
- Asistencia preparada para confirmación por PIN/código de clase.
- Arquitectura preparada para Supabase Auth, PostgreSQL, RLS y Edge Functions.
- Asistente IA diseñado para operar mediante backend seguro, sin exponer claves secretas.

## Seguridad
Nunca colocar una clave privada de backend o IA en el navegador. Las operaciones privilegiadas deben pasar por un backend seguro o Edge Function.

## Próximos módulos
Notas, actividades, notificaciones, conversaciones IA, seguimiento docente/orientación y políticas RLS completas.
